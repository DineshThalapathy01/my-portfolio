Responsibilities

  • Project were begun at January 2025; developed and maintained multiple modules for a Bihar government Labour welfare portal using Angular 16, Java Spring Boot, and PostgreSQL, including Profile Update, Application Renewal (Direct and Approval-based), Payment Gateway, RBAC (Geo x User x Role Mapping, Role x Menu Mapping), CMS, DMS, and Chat-bot (Java) which are the modules worked by myself.
  • Worked on large-scale government welfare application serving 35+ lakh registered workers across Bihar state.
  • AADHAR INTEGRATION: Implemented Aadhar Integration in BBOCW Application – AADHAR OTP, AADHAR EKYC, AADHAR BIO-METRIC.
  • For Registration initially AADHAR BIO-METRIC will be required as Mandatory.
  • Bio Metric Device Configuration worked in RD Services – Mantra, Morpho these specific 2 devices worked and integrated in our application – where the device returns the format which needed a setup to communicate with Aadhaar UIDAI API or vendor API; accessing both were worked.
  • All Logical Conditions and Payment Values were handled only in the backend safely and securely.
  • Worked in Java Spring Security – Login accessing with JWT concept (Access Token, Refresh Token, …), CAPTCHA verification, encryption & decryption.
  • Implemented Profile Update module with Angular reactive forms for user data management, integrated with Spring Boot REST APIs for secure updates and JPA for database persistence.
  • Built Application Renewal modules (Direct Renewal and Approval Process), enabling workers to renew registrations with form validation, file uploads (DMS), and admin approval workflows, using Hibernate and Spring Security for role-based access.
  • Integrated Payment Gateway module with secure transaction processing, handling payment statuses and generating receipts, integrated with external APIs and PostgreSQL for transaction logging.
  • Designed RBAC system with Geo x User x Role Mapping and Role x Menu Mapping, implementing dynamic menu rendering based on user roles and geographic assignments using Angular directives and Spring Security.
  • Developed CMS module for managing content (e.g., Directory, Organization Structure) with create, update, and list functionalities, supporting multilingual (English/Hindi) interfaces and dynamic filtering by division, district, and designation.
  • Built DMS module for secure file uploads, with validation for file types/sizes and storage in PostgreSQL, integrated with Spring Boot for efficient file handling.
  • Implemented Chatbot module for the website, providing dynamic user interactions with predefined responses, built using Angular and REST APIs for real-time query handling.
  • Managed database design with PK Id Mapping for master tables, ensuring referential integrity and optimized query performance using JPA and indexed columns.
  • Collaborated with a team of 8 developers, integrating frontend and backend via RESTful APIs, using Git for version control, used Docker for deployment of application. Conducted client syncs in Patna to align with government requirements.
  • Ensured security with Spring Security for role-based access (SUPERADMIN, USER), data validation, and audit logging (createdBy, updatedBy, timestamps). Optimized performance with indexed queries and caching.
